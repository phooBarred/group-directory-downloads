# Group Directory for Android

Official signed APK downloads and update feed. Source code remains private. No user data or linked sessions are stored here.

Download from [Releases](https://github.com/phooBarred/group-directory-downloads/releases). Install over your existing app; do not uninstall or clear data. Android 9 or newer.

Starting with 0.3, open **Settings → Check for updates** and tap **Install update** when a newer release is available. Android asks for installation approval.
